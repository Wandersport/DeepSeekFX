# DeepseekFX

Source for the DeepseekFX marketing site — a single-page landing page (`index.html`) presenting "Advanced Trading Robots for MT4/MT5": AI-assisted analysis, customizable Expert Advisor (EA) parameters, and product/pricing cards for the EAs being sold.

## What's in here

- `index.html` — the entire site (HTML, CSS, and any JS all inline in one file). Sections include a hero banner, a features grid, a products/pricing grid, and a testimonials/contact area.

## Running it locally

No build step — it's a static file. Just open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
